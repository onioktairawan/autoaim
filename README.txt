CARA BUILD
1. Buka folder ini di Android Studio (File > Open). Tunggu Gradle sync (otomatis bikin wrapper).
2. Ganti isi app/src/main/assets/autoaim.js dengan kode JS lu (paste utuh, tanpa diubah).
3. Build > Build APK(s)  ->  app/build/outputs/apk/debug/app-debug.apk
   (atau Build > Generate Signed Bundle / APK untuk release)
4. Install di HP, buka AutoAim, isi URL game, tekan Open Game.

Tombol layar: AUTO / TRICK / BALL(ball-in-hand) / NEXT / MODE / ◀ ▶ (fine-tune, tahan untuk repeat) / SHOOT / HUD.
Tap bola di meja = bidik bola itu. HUD bisa digeser pakai jari.
